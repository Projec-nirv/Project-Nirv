# Project NIRV Research Discovery

Use this skill when an agent needs to discover, summarize, or cite Project NIRV public research.

## Entry points

- Site guide: https://projectnirv.studio/llms.txt
- Research index: https://projectnirv.studio/blog
- RSS feed: https://projectnirv.studio/rss.xml
- API catalog: https://projectnirv.studio/.well-known/api-catalog

## Guidance

1. Start with `llms.txt` for the compact map of the site.
2. Use the research index or RSS feed to discover current articles.
3. Prefer article pages as canonical sources for citations.
4. Treat Project NIRV articles as analysis and synthesis, not as primary data sources unless a cited source is explicitly named.
