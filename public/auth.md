# Project NIRV Agent Authentication

Project NIRV currently exposes public, read-only research and discovery resources.

## Authentication status

- Public research pages do not require authentication.
- `llms.txt`, RSS, API catalog, MCP server card, and agent skills metadata are public.
- There are currently no protected public APIs that require OAuth or OpenID Connect credentials.

## Agent usage

Agents may crawl and cite public Project NIRV pages according to the site's robots and metadata signals. Prefer canonical article URLs and include source attribution when summarizing or quoting.

## Contact

For access or integration questions, use the public Project NIRV website contact path when available.
